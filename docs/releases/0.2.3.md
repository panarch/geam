# Geam 0.2.3

Geam 0.2.3 turns Rust embedding and host-provider setup into progressive,
executable learning paths, clarifies automatic provider discovery, and hardens
publication of the release-coupled reference packages.

## Changes

- Learn Rust embedding one step at a time through independently runnable
  examples for a first call, nested data, Gleam package dependencies,
  caller-owned IO, and an external provider, followed by a complete
  application. The README and embedding guide follow the same progression, and
  Acceptance runs every example.
  ([#156](https://github.com/panarch/geam/pull/156), @panarch)
- Follow a host provider from its Gleam external declaration to its Rust
  implementation and use through `geam run`. The guide now explains the split
  between the Hex package and its companion Rust crate, the crates.io naming
  convention used for automatic discovery, and the interactive selection and
  approval flow. Provider examples are grouped into an ordered path under
  `examples/provider`.
  ([#158](https://github.com/panarch/geam/pull/158), @panarch)
- See the current crates.io version, license, CI status, and Rust API
  documentation directly from the README.
  ([#155](https://github.com/panarch/geam/pull/155), @panarch)
- Publish the reference provider with a lock resolved against the released
  registry crates instead of checkout patches. Pre-1.0 Hex publication now
  supplies Gleam's required acknowledgement, preserves command failures through
  the logging pipeline, and rejects a successful no-op instead of treating it
  as a completed upload.
  ([#153](https://github.com/panarch/geam/pull/153),
  [#154](https://github.com/panarch/geam/pull/154), @panarch)

## Compatibility

- Existing standalone projects, Rust embedding applications, and host-provider
  crates require no source migration from Geam 0.2.2. The Rust 1.96,
  Gleam 1.18.1, and 64-bit target requirements are unchanged.
- Repository examples now live under `examples/embedding` and
  `examples/provider`. Update local links or scripts that referenced their
  former top-level paths.
- The public `example_text_pattern` Hex package and
  `geam-example-text-pattern` Rust provider follow the Geam release version;
  use version 0.2.3 of both when testing this release.
